# Security Policy

## Supported Versions

Only the latest version of Lass Download Manager is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v5.0.x  | :white_check_mark: |
| < v5.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public issue.

Instead, please report it privately using GitHub's **Security Advisories** feature (go to the "Security" tab of this repository and click "Report a vulnerability"), or send an email to **fbmi8mh@gmail.com**.

I will try to acknowledge your report within 48 hours. If the vulnerability is accepted, I will work on a fix and release a security update as soon as possible. If declined, I will explain why it is not considered a security issue.
